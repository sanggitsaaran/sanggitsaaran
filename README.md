## 🚀 Featured Projects

### 🔹 Smart IoT-ML Food Monitoring System
- Real-time inventory monitoring using **ESP32, RFID, DHT22, and Computer Vision**
- **88.33% accuracy** using MobileNetV2 + SVM
- Full-stack system with React dashboard, Flask microservices, ML expiry prediction
- Integrated LLM APIs for recipe generation using near-expiry food items

### 🔹 Hand Gesture-Driven Speech Aid (IEEE Publication)
- Sensor-based gesture recognition system
- **90.91% accuracy** using KNN
- End-to-end pipeline with serial communication, LCD output, and audio feedback
- Published on **IEEE Xplore**

### 🔹 Bayesian Framework for Perovskite Materials
- Hierarchical ensemble (Bayesian Ridge + RF + XGBoost)
- **98%+ R²** for band gap and formation energy prediction
- Feature augmentation with LIME analysis
- LLM-based scientific validation system
